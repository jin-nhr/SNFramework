# SN Framework

Direct2D / XAudio2 をベースにした **軽量・高速な自作ゲーム／アプリ向けフレームワーク**。  
GUI、サウンド、レイヤ管理、入力統合など、2D アプリケーションに必要な基盤を最小構成で提供します。

> ⚠️ **現在開発中（WIP）**  
> 個人による **独学・我流** の開発のため、設計方針や実装は一般的なフレームワークとは異なる場合があります。  
> 機能追加・仕様変更を継続的に行っており、安定版ではありません。

---

## 📌 特徴

### ● 軽量設計
- Direct2D1.1 と XAudio2 を直接扱うことで、余計なオーバーヘッドを排除。

### ● レイヤベースの画面管理（SNLayerController）
- Scene や GUIWindow をレイヤとして扱い、明確なライフサイクル（Entry / Exit / Draw）を提供。

### ● GUI システム（SNGUIWindow / SNGUIButton）
- ウィンドウ描画（9分割タイル）
- ボタンのフォーカス管理
- マウス／ゲームパッドの入力統合
- 決定／キャンセル／フォーカス移動音の再生
- ウィンドウ開閉音（開く音のみ）

### ● 入力統合（SNFocus / SNFocusGroup）
- マウスとゲームパッドを同時に扱えるフォーカスシステム
- ボタンの選択、決定、キャンセルを統一的に処理

### ● サウンド再生（SNSoundEffect）
- 効果音の生成・再生・破棄を簡潔に扱える API

### ● リソース管理（SNGraphicsResManager）
- 画像・ビットマップ・GUI素材のロード／解放を自動化

---

## 🚀 ビルド方法

- Visual Studio 2022 Community  
- Windows 10 / 11  
- 追加ライブラリ不要  
- Direct2D / XAudio2 は Windows 標準 API を使用

- **物理演算の導入（軽量 2D 物理）**
  - 衝突判定

  - 簡易剛体シミュレーション

  - Transform（位置・回転・スケール）
  - Sprite / Animator
