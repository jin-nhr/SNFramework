# SN Framework

C++ & Direct2D / XAudio2 をベースにした Windows向けの **軽量・高速な自作ゲーム／アプリ向けフレームワーク**。  
GUI、サウンド、レイヤ管理、入力統合など、2D アプリケーションに必要な基盤を最小構成で提供します。

> ⚠️ **現在開発中（WIP）**  
> 個人による **独学・我流** の開発のため、設計方針や実装は一般的なフレームワークとは異なる場合があります。  
> 機能追加・仕様変更を継続的に行っており、安定版ではありません。


---

## 📌 特徴

### ● ポリシー
- Windows標準の機能のみを使い、外部ライブラリ等を必要としないフレームワークを構築する
- アプリケーションの移植性などを鑑み、環境依存の型などをヘッダーファイルに記述しない
- C++の標準ライブラリを含むテンプレートは保守性の観点から使用しない
- フレームワーク内のクラスはコピー禁止措置を設けていないが、設計上コピーを想定していない

### ● 軽量設計
- Direct2D1.1 と XAudio2 を直接扱うことで、余計なオーバーヘッドを排除。

### ● アプリケーション
- Scene による画面/状態遷移の制御（Entry / Exit / Draw）
- 専用のアプリケーションスレッドでの制御

### ● GUI 
- SceneをベースとしたGUIシステムの構築
- 統合された入力デバイスによるUI画面のフォーカス制御

### ● 入力機能
- マウス、キーボード、ゲームパッド(2つまで)の入力
- 複数デバイスの入力を統合して内部イベントに変換

### ● Audio/Video機能
- XAudio2でのメモリ上に展開したPCMの再生機能

### ● グラフィックス機能
- Direct2Dを用いた画面描画機能
- アプリケーション、GUIとの一貫した描画パイプライン
- 画像描画(透過、半透過、拡大縮小)
- カラーマトリクスによる色変換

### ● ストレージアクセス機能
- 非同期でのストレージアクセス機能
- フォルダ制御、ファイル制御を実装

### ● コーデック機能
- Windows 標準 API（WIC / Media Foundation）を利用した非同期デコード／エンコード
- ストレージアクセス機能と連携した非同期読み込み
- 対応フォーマット：MP3、PNG

### ● リソース管理
- 画像、音声データなどのリソースの一括管理


---

## 🚀 ビルド環境

- Visual Studio 2022 Community  
- Windows 11
- 追加ライブラリ不要  
- Direct2D / XAudio2 / Windows 標準 API を使用
